# Assertion Commander
This evaluation tool was developed by **Severin Primbs** as part of a Master's thesis with the title:<br/>
**AsserT5: Automated Generation of Test Assertions using a Large Language Model Approach**
## Installation

To run the script, you will need a common Python 3.10 variant with the poetry package manager installed. 
Additionally, Java 17 must be installed, or the `JAVA_HOME` environment variable must be appropriately configured with the path of java 17.

```bash
poetry env use 3.10
poetry install
```
## Metric Evaluation
This script has been developed as part of a Master's thesis to evaluate the quality of assertions generated by various AI models. The supported models include Toga, Atlas, Doprebart, ChatGPT, and the custom-built model AsserT5. The script calculates various metrics to assess the quality of the generated assertions. The available metrics are:

1. **Accuracy**: Measures the proportion of correct predictions out of total predictions made.
2. **Syntactic Correctness**: Evaluates grammatical accuracy of generated text.
3. **Assertion Types**: Differentiates between types of claims made by a model.
4. **BLEU Score**: Evaluates machine-translated text by comparing it to human reference translations.
5. **Mean Squared Error (MSE)**: Measures average squared difference between actual and predicted values in regression tasks.
6. **Conditional Accuracy**: Measures accuracy when the predicted assertion was correct.
7. **Evaluated Predictions**: Number of evaluated Predictions


### Usage

The script accepts various command-line arguments to customize the evaluation. Here are the available arguments:

```bash
python evaluate.py --model MODEL --type DATA_TYPE [Options]
```

- `--model`: Specifies the type or identifier of the model to use. This argument is required.
- `--type`: Specifies the type or identifier of the dataset to use. This argument is required.
- `--root-dir`: Specifies the root directory of the data. Default is "evaluation-data".
- `--batch-size`: Specifies the batch size for processing data. Default is 32.
- `--top-k`: Determines the number of top results to consider. Default is 1.
- `--model-url`: Specifies the URL where the model is hosted. Default is "http://localhost:8080/".
- `--number-assertions`: Sets the number of assertions to be considered. Default is 1.
- `--export`: Specifies the type or identifier of the exporter to use. Default is "file:console".
- `--export-dir`: Specifies the root directory of the metrics to be exported. Default is "results".
- `--pred-file`: Specifies the file for already created predictions and only evaluates them.
- `--epoch`: Specifies the epoch under evaluation and stops if the set epochs do not match.
- `--data-type`: The type of the data (depends on the selected models).

### Example

```bash
poetry run evaluate \
    --model asserT5 \
    --batch-size 16 \
    --top-k 10 \
    --number-assertions 1 \
    --root-dir dummy-data \
    --export-dir results \
    --type test \
    --model-url http://localhost:8080 \
    --data-type raw
```

The instruction calls for the retrieval of the top 10 assertions from the model named asserT5. 
Operating with a batch size of 16, it employs individual assertions for each test case. 
The data utilized originates from the provided dummy dataset and is exported to the designated results directory. 
The model server is running on localhost, accessible via port 8080.



## Assertion Comparison Script (Raw vs. Abstract)

This script is designed to compare predictions made by a model on raw data versus abstracted data. The comparison results are written to an output file.

### Usage

```bash
poetry run compare -r RAW_FILE -a ABSTRACT_FILE -o OUTPUT_FILE
```

- `-r, --raw-file`: Specifies the path to the input file containing predictions made on raw data.
- `-a, --abstract-file`: Specifies the path to the input file containing predictions made on abstracted data.
- `-o, --output-file`: Specifies the directory where the comparison results should be saved.

## Unknown Abstract Token Evaluation Script

The script performs evaluation on abstract predictions and computes statistics based on the evaluation results. 
The script categorizes predictions based on the count of unknown abstract tokens and generates a distribution of failing assertion types.

### Usage

```bash
poetry run evaluate-abstract -a ABSTRACT_FILE -d DATA_FILE -o OUTPUT_FILE
```

- `-a, --abstract-file`: Specifies the path to the input file containing abstract predictions.
- `-d, --data-file`: Specifies the path to the input file containing data.
- `-o, --output-file`: Specifies the directory where the evaluation results should be saved.


## Filter Predictions

This script handles files based on allowed line numbers and exports only the lines specified.

### Usage

```bash
poetry run filter-predictions -l ALLOWED_LINES -i INPUT_FILE -o OUTPUT_FILE
```

- `-l, --allowed-lines`: Specifies the path to the file containing allowed line numbers.
- `-i, --input-file`: Specifies the path to the input file.
- `-o, --output-file`: Specifies the directory where the exported lines should be saved.

## JUnit Assertion Filter
This script filters rows in a CSV file based on the presence of valid JUnit assertions made by ChatGPT.

## Usage

```bash
poetry run gpt-filter -i INPUT_FILE -o OUTPUT_FILE
```

- `-i, --input_file`: Specifies the path to the input CSV file.
- `-o, --output_file`: Specifies the path to the output CSV file.
